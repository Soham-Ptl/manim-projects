# Manim Projects

A collection of mathematical visualizations and animations created using [Manim Community](https://www.manim.community/) and Python.

The goal of this repository is to explore mathematical concepts through animation, visualization, and experimentation.

## Projects

| [Pythagorean Theorem](./pythagorean-theorem/) | A visual proof of the Pythagorean theorem using geometric transformations and animations. |

## Running the Projects

Clone the repository:

```bash
git clone https://github.com/Soham-Ptl/manim-projects.git
cd manim-projects
```

Create and activate a virtual environment:

```bash
python3 -m venv manim-env
source manim-env/bin/activate
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Then navigate to a project and render it using Manim:

```bash
cd pythagorean-theorem
manim -pqh pythagorean_theorem.py vod
```
